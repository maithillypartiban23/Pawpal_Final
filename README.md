# pawpal

PawPal is a Flutter-based mobile application designed for pet lovers to donate, manage profiles, and support pets in need. This project integrates user authentication, profile management, donation tracking, and wallet functionality. It follows a modern UI with a brown theme for a warm and friendly look.

Features

User Authentication
-Email and password login
-Remember me functionality using SharedPreferences
-User registration
-Profile Management
-View and edit profile details: Name, Email, Phone
-Update profile image from camera or gallery
-Cropping support for profile images

Donations
-View donation history (money, supplies, other types)
-Clear display of donation details: Type, Description, Amount, Date
-Proper card layout for readability
-Drawer Navigation
-Home, My Donations, Profile, and Logout
-Consistent brown theme matching login page
